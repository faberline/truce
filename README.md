# truce

Forward-only PostgreSQL schema evolution control plane.

Nothing is implemented yet. This repository holds the backlog that moved here
from faberline/axiom when the monorepo was split: the capability issues of the
epic faberline/axiom#2886 — the capability contract and single `truce` CLI, the
registry catalog and catalog fingerprints, the migration version DAG and
compatibility gates, server-side execution with recovery, pinned consumer
bindings, environment promotion, and container and Kubernetes artifacts.
